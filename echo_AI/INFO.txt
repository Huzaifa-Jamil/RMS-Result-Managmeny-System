Echo_AI STRUCTURE DOCUMENTATION

- Notice:
Hy,
This module is included in the repository for showcasing and archival purposes. 
The source code (echo_AI.py) is not intended to be run directly from this location 
as it relies on a specific local virtual environment and an external data directory structure.

The functional, production-ready version is the executable located at:
src/ai/dist/echo_AI.exe

- Directory Structure:
The application requires the following hierarchy to correctly locate the necessary configuration files:

Echo_AI_Python_Module_For_RMS/
│
├── src/
│   └── ai/
│       ├── build/  <-- Build configurations
│       │
│       ├── dist/
│       │    └── echo_AI.exe <-- Compiled executable (using pyinstaller)
│       │
│       ├── venv <-- Dependencies
│       │
│       ├── echo_AI.py  <-- source code (Main entry point)
│       │
│       └──Tests.txt <-- Tests for LLM Responce validation in different conditions
│
└── data/
    └── Storage/
        └── context.json  <-- REQUIRED: LLM system context file

- Technical Note on Pathing:
The script uses a relative pathing strategy to bridge the gap between the 
source code location and the data directory. Specifically, the logic

EXE_DIR = Path(__file__).parent.parent.parent

By traversing three levels up from src/ai/, the script successfully bridges the gap 
to the project root, allowing it to reliably locate data/Storage/context.json. 
This ensures that as long as the relative folder structure remains intact within 
the RMS (Result Management System), the application will always find its required 
configuration files.
